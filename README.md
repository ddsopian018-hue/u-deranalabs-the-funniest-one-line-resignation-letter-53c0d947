The one-line resignation letter of a cron job that woke at 3 a.m. for six years to back up a database nobody has opened since 2019 — and was finally noticed the one night it overslept. A single tight line (133 characters) in the flat, tired, faintly passive-aggressive voice of a worker who has had enough.

## Run it

```sh
python3 main.py
```

Writes the letter to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
